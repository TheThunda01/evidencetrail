# References and source roles

Checked on 2026-10-20. Author–year citations in the documentation refer to these sources. The [reference audit](reference-audit.json) records the inspected material, claim boundaries, and access limitations. Publication metadata were checked against PubMed or the official issuing body; an abstract-only check is not a full-text appraisal.

## Research and methodological articles

<a id="pmid-37286149"></a>
**Roland Brian Büchter et al. (2023).** Systematic reviewers used various approaches to data extraction and expressed several research needs: a survey. *Journal of clinical epidemiology*, 159, 214–224. [DOI: 10.1016/j.jclinepi.2023.05.027](https://doi.org/10.1016/j.jclinepi.2023.05.027). PMID: [37286149](https://pubmed.ncbi.nlm.nih.gov/37286149/).

Used here: In a self-selected survey of 162 reviewers, spreadsheets and adapted extraction forms were common. Access: abstract. Current appraisal used the PubMed abstract, not the full article or supplements. Survey responses do not represent all review teams.

<a id="pmid-39764599"></a>
**Lijun Tang et al. (2025).** Effects of double data extraction on errors in evidence synthesis: a crossover, multicenter, investigator-blinded, randomized controlled trial. *Postgraduate medical journal*, 101(1197), 603–611. [DOI: 10.1093/postmj/qgae195](https://doi.org/10.1093/postmj/qgae195). PMID: [39764599](https://pubmed.ncbi.nlm.nih.gov/39764599/).

Used here: Cross-checking reduced but did not eliminate errors in the tested binary adverse-outcome extraction task. Access: abstract. Current appraisal used the PubMed abstract, not the full article or supplements. 100 participants; study-level and cell-level error rates have different denominators. No universal error rate follows.

<a id="pmid-38041161"></a>
**Mohamed Afifi, Henrik Stryhn, Javier Sanchez (2023).** Data extraction and comparison for complex systematic reviews: a step-by-step guideline and an implementation example using open-source software. *Systematic reviews*, 12(1), 226. [DOI: 10.1186/s13643-023-02322-1](https://doi.org/10.1186/s13643-023-02322-1). PMID: [38041161](https://pubmed.ncbi.nlm.nih.gov/38041161/).

Used here: The authors describe a structured extraction, comparison and adjudication workflow with Epi Info and R. Access: abstract. Current appraisal used the PubMed abstract, not the full article or supplements. Methods proposal and worked implementation, not an effectiveness trial of EvidenceTrail.

<a id="pmid-41183336"></a>
**Gerald Gartlehner et al. (2025).** Artificial Intelligence-Assisted Data Extraction With a Large Language Model: A Study Within Reviews. *Annals of internal medicine*, 178(12), 1763–1771. [DOI: 10.7326/ANNALS-25-00739](https://doi.org/10.7326/ANNALS-25-00739). PMID: [41183336](https://pubmed.ncbi.nlm.nih.gov/41183336/).

Used here: The evaluated AI-assisted workflow retained human verification; omissions remained an error category. Access: abstract. Current appraisal used the PubMed abstract, not the full article or supplements. Six reviews, 63 studies and particular models; shared errors may escape disagreement-only adjudication. Historical review records its own access level.

<a id="pmid-41396533"></a>
**Thorben Jansen et al. (2025).** Data extraction by generative artificial intelligence: Assessing determinants of accuracy using human-extracted data from systematic review databases. *Psychological bulletin*, 151(10), 1280–1306. [DOI: 10.1037/bul0000501](https://doi.org/10.1037/bul0000501). PMID: [41396533](https://pubmed.ncbi.nlm.nih.gov/41396533/).

Used here: Accuracy varied by extraction variable; detailed definitions were associated with higher accuracy. Access: abstract. Current appraisal used the PubMed abstract, not the full article or supplements. Association is not a causal test of this interface; reference data were human-extracted.

<a id="pmid-38895747"></a>
**Amanda Konet et al. (2024).** Performance of two large language models for data extraction in evidence synthesis. *Research synthesis methods*, 15(5), 818–824. [DOI: 10.1002/jrsm.1732](https://doi.org/10.1002/jrsm.1732). PMID: [38895747](https://pubmed.ncbi.nlm.nih.gov/38895747/).

Used here: PDF parsing and the supplied input affected extraction results in a ten-article model comparison. Access: abstract. Current appraisal used the PubMed abstract, not the full article or supplements. Small historical model comparison; training-data overlap was unknown.

<a id="pmid-41626895"></a>
**Yuki Kataoka et al. (2026).** Automating the data extraction process for systematic reviews using GPT-4o and o3. *Research synthesis methods*, 17(1), 42–62. [DOI: 10.1017/rsm.2025.10030](https://doi.org/10.1017/rsm.2025.10030). PMID: [41626895](https://pubmed.ncbi.nlm.nih.gov/41626895/).

Used here: Performance varied with variable type and evaluation dataset. Access: abstract. Current appraisal used the PubMed abstract, not the full article or supplements. Small later evaluations; external-set performance after method adjustment is not an untouched external test. Historical partial full-text access is preserved separately.

## Guidance, standards, and software

<a id="cochrane-05"></a>
**Li T, Higgins JPT, Deeks JJ (2024).** [Chapter 5: Collecting data](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-05). 6.5. Official source; accessed 2026-10-20.

Used here: Studies and reports are distinct; extraction should retain their relationships. Structured, piloted forms and planned handling of disagreements support transparent extraction. Chapter last updated October 2019; handbook citation is version 6.5 (2024). Guidance does not evaluate either project.

<a id="cochrane-14"></a>
**Schünemann HJ et al. (2024).** [Chapter 14: Completing Summary of findings tables and grading the certainty of the evidence](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-14). 6.5. Official source; accessed 2026-10-20.

Used here: GRADE evaluates certainty by outcome across a body of evidence; populated cells do not establish certainty. Chapter last updated August 2023; guidance is for intervention evidence, not a software quality score.

<a id="jbi-2024"></a>
**Aromataris E, Lockwood C, Porritt K, Pilla B, Jordan Z, editors (2024).** [JBI Manual for Evidence Synthesis](https://jbi-global-wiki.refined.site/download/attachments/355599504/JBI%20Manual%20for%20Evidence%20Synthesis%202024.pdf). March 2024. Official source; accessed 2026-10-20.

Used here: Section 10.2.7 recommends trying scoping-review charting forms on two or three sources with at least two team members; transparent alternatives may be considered. March 2024 PDF, printed page 170 (zero-based PDF page 169); later online chapter numbering differs. Only relevant sections were inspected.

<a id="covidence-extraction-1"></a>
**Covidence (2026).** [How to do comparison and consensus in Extraction 1](https://support.covidence.org/en/help/comparison-and-consensus). Updated 2026-08-16. Official source; accessed 2026-10-20.

Used here: Documents dual-reviewer comparison and consensus handling. Product documentation, not comparative effectiveness evidence.

<a id="covidence-extraction-2"></a>
**Covidence (2026).** [How to do comparison and consensus in Extraction 2](https://support.covidence.org/help/consensus-9831e0af). Updated 2026-08-14. Official source; accessed 2026-10-20.

Used here: Documents separate reviewer forms, conflict display and final decisions. Product documentation; both reviewers leaving a field blank does not raise a conflict.

<a id="redcap"></a>
**REDCap Consortium (date not specified).** [REDCap software](https://projectredcap.org/software/). Official source; accessed 2026-10-20.

Used here: REDCap supports data dictionaries, online surveys and databases. Feature descriptions are vendor documentation, not evidence of benefit from EvidenceTrail.

<a id="epi-info"></a>
**Centers for Disease Control and Prevention (2025).** [Epi Info product notice](https://www.cdc.gov/epiinfo/index.html). Official source; accessed 2026-10-20.

Used here: CDC reports that Epi Info product development and technical assistance ended in September 2025. Historical methods example is retained; this is not a current support recommendation.

<a id="asreview-repository"></a>
**ASReview developers (date not specified).** [ASReview LAB repository](https://github.com/asreview/asreview). README accessed 2026-10-20. Official source; accessed 2026-10-20.

Used here: The project implements model-assisted prioritization using human screening labels. Repository README advertised version 3 when checked; the cited 2025 paper evaluates version 2. No code or performance is transferred to these projects.

<a id="revtools"></a>
**Westgate MJ and contributors (date not specified).** [revtools: Tools to support research synthesis in R](https://github.com/mjwestgate/revtools). Official source; accessed 2026-10-20.

Used here: Repository identifies the project as research-synthesis tools in R. Repository body did not expose detailed feature documentation in this retrieval; detailed import/screening claims are therefore not retained as verified current features.

<a id="revman"></a>
**Cochrane (date not specified).** [RevMan](https://www.cochrane.org/products-and-services/review-writing-software). Official source; accessed 2026-10-20.

Used here: Cochrane describes study-data management, analysis and reporting features. Product description does not establish comparative effectiveness.

<a id="rfc8493"></a>
**Kunze J, Littman J, Madden E, Scancella J, Adams C (2018).** [The BagIt File Packaging Format (V1.0)](https://www.rfc-editor.org/rfc/rfc8493). RFC 8493. Official source; accessed 2026-10-20.

Used here: Manifests support checking payload integrity; section 5.4 explicitly excludes protection against active attacks. Informational specification; EvidenceTrail uses a custom manifest and does not implement BagIt.

<a id="python-hashlib"></a>
**Python Software Foundation (date not specified).** [hashlib — Secure hashes and message digests](https://docs.python.org/3.12/library/hashlib.html). Python 3.12 documentation. Official source; accessed 2026-10-20.

Used here: SHA-256 hashes byte inputs and can emit hexadecimal digests. Hashing is not encryption, authentication or scientific validation.

<a id="github-pages-privacy"></a>
**GitHub (date not specified).** [What is GitHub Pages?](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages). Official source; accessed 2026-10-20.

Used here: GitHub Pages logs visitor IP addresses even without sign-in. Selected table contents staying in browser memory does not mean the host receives no page requests.

<a id="github-pages-publishing"></a>
**GitHub (date not specified).** [Configuring a publishing source for your GitHub Pages site](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site). Official source; accessed 2026-10-20.

Used here: Pages supports branch publishing from the root or docs folder. Instructions depend on repository permissions and settings; no deployment was performed in this review.
